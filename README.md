# Finaliza Pro

App web inicial para análise de **finalizações + gols**.

## Como usar
1. Abra `index.html` no navegador.
2. Use "Carregar exemplo" ou informe os times.
3. A tela calcula médias, linhas de finalizações, Over 1.5 e um Score PRO.

## Próxima etapa
Para transformar este protótipo em um app com dados reais, conecte uma API de futebol (jogos, estatísticas, finalizações e gols) ao backend. O cálculo atual está preparado para receber esses dados.

## Importante
O Score PRO é uma ferramenta estatística e não garante resultado de aposta. Use dados reais e faça gestão de banca.
